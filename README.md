# Raster Studio

Aplikasi web client-side untuk mengubah JPG/PNG menjadi raster/halftone.

## Fitur
- Upload gambar JPG, PNG, WEBP, dan format gambar browser lainnya
- Halftone/dot screen dengan ukuran sel, ukuran dot, dan sudut screen
- Floyd–Steinberg dithering
- Bayer ordered dithering
- Threshold/binary
- Brightness, contrast, invert
- Preview real-time
- Export PNG
- Semua pemrosesan dilakukan di browser; gambar tidak perlu dikirim ke server

## Menjalankan

```bash
npm install
npm run dev
```

Lalu buka URL Vite yang ditampilkan.

## Build

```bash
npm run build
npm run preview
```
